# Incident INC-002 - Suspicious PowerShell Execution

## Severity

MEDIUM

## Status

Open

## Detection

PowerShell execution was detected through Windows process creation Event ID 4688.

## Account

alice

## Process

powershell.exe

## Parent Process

explorer.exe

## Event Time

2026-08-23 09:15:27

## Evidence

The following Windows process creation event was observed:

- Event ID: 4688
- Account: alice
- Process: powershell.exe
- Parent Process: explorer.exe

## MITRE ATT&CK

T1059.001 - PowerShell

## Analyst Assessment

PowerShell is a legitimate Windows administration and automation tool, so its execution alone does not confirm malicious activity.

The event should be investigated to determine whether the PowerShell activity was authorized and whether any suspicious commands or scripts were executed.

## Recommended Actions

1. Confirm whether the user `alice` was authorized to execute PowerShell.
2. Review the PowerShell command line associated with the process.
3. Review PowerShell Script Block Logging if available.
4. Check for child processes launched by PowerShell.
5. Review network connections generated by the PowerShell process.
6. Check whether the activity occurred near other suspicious events.
7. Escalate the incident if malicious commands or unauthorized activity are identified.
